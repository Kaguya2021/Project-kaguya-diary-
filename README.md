# Kaguya Diary :)

Современный электронный дневник и библиотека для 9 «В» класса школы №104 в премиальном дизайне Cloud AI.

## Инструкция по запуску

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` на основе `.env.example` и заполните данные для Neon PostgreSQL и Telegram-бота.
3. Выполните SQL-схему из `database/schema.sql` в вашей базе данных Neon.
4. Поместите обложки книг в `public/photo/` (`1.png`, `2.png` ... `15.png`).
5. Запустите проект:
   ```bash
   npm start
   ```
